# 资源共享 v2.0

资源合集分享工具 — Tauri轻量级方案

## 功能
- 17种主题背景切换
- QQ交流频道与微信公众号
- 夸克/迅雷/UC网盘资源合集
- 响应式PC和手机端适配
- 所有链接自动调用系统默认浏览器

## 技术栈
- **PC端**: Tauri 2 + Rust + WebView2 (仅4MB)
- **Android**: Capacitor + WebView (3.9MB)
